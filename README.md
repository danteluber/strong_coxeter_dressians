This repository contains computations related to the paper [Minuscule Coxeter Dressians](https://arxiv.org/abs/2512.09703). We study the tropical prevarieties associated with strong exchange equations of Coxeter matroids of minuscule Lie type. In particular, we are interested in the induced subdivisions of the Coxeter matroid polytopes. This is based on joint work with Andreas Gross and Kevin Kühn.
