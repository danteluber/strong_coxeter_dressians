This repository contains computations related to the paper [Minuscule Coxeter Dressians](https://arxiv.org/abs/2512.09703). We study the tropical prevarieties associated with strong exchange equations for Coxeter matroids of minuscule Lie type. In particular, we are interested in the induced regular subdivisions of the Coxeter matroid polytopes. This is joint work with Andreas Gross and Kevin Kühn. These computations were performed in the OSCAR Computer Algebra Sytem 1.90 Dev version, running in Julia 1.12.6. If you are using different OSCAR or Julia versions and encounter probems, please contact us.
